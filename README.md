# 1T-and-3T-DRAM-using-Cadence
This repository presents the design and simulation of 1-Transistor (1T) DRAM and 3-Transistor (3T) DRAM memory cells using the Cadence Virtuoso design environment. The project focuses on schematic design, transient analysis, read/write operations, and performance comparison of both DRAM architectures.

The simulations were carried out to analyze:

Data storage capability
Read and write functionality
Retention characteristics
Power consumption
Access speed
Stability of memory cells
